# Changelog

All dates use Asia/Taipei. Versions through `0.2.0-preview.7` are retrospective labels for existing commits; those builds originally displayed a generic preview version. Links identify their exact source state. Earlier unpublished work is included in the initial public package rather than assigned invented release dates.

## 0.3.0 — 2026-10-28

## 0.2.0-preview.14 — 2026-10-28

## 0.2.0-preview.12 — 2026-10-28
